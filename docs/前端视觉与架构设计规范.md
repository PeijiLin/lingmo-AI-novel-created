# 小说创作平台 · 前端视觉与架构设计规范

> 版本 v0.3.1（评审稿）
> 适用范围：`novel-creation-front` 全量重构（表现层重做 + 架构收敛）
> 本文档是前端重构的唯一设计依据，评审通过后进入编码。

---

## 0. 定位与目标

### 0.1 产品定位

**核心：AI 小说创作平台。** 阅读 / 发现 / 排行是**辅助与展示层**，用于沉淀创作成果、激发创作意愿，**不是对等业务**。

- 进入应用的**第一落点是创作**（工作台 + 知识库 + AI 多智能体流水线）。
- 阅读 / 发现 / 排行服务于"我创作的东西能被人看到、我也能被别人的作品激发"，是创作的**正向反馈闭环**，而非门户首页。
- 一切设计资源优先投向创作链路；门户仅是创作成果的展示橱窗。

```
         ┌──────────────────────── 创作（核心）────────────────────────┐
         │  作者 → 知识库(角色/世界观/伏笔) → AI 流水线(四档) → 稿纸续写    │
         └────────────────────────────────────────────────────────────┘
            │ 发布
            ▼
         （展示/反馈，辅助） 作品被阅读 → 榜单/发现 → 激发读者创作
```

### 0.2 现状问题

现有前端（Vue 3.5 + Element Plus + Tailwind 4 + Tiptap）三类问题：

1. **能力断层**：后端 `CreationPipelineController` 多智能体流水线（四档模式、SSE stage、异步任务、token 用量）前端完全不可见，核心卖点无法演示。
2. **工程底座缺口**：非 git 仓库、零测试、三套 HTTP 通路并存、base 硬编码。
3. **视觉无品牌**：Element Plus 企业后台气质与创作产品不符。

**目标**：为「以创作为核心的 AI 小说创作平台」建立**原创视觉体系**（纸墨书卷），完成架构收敛与 pipeline 对接，让创作成果可展示、被阅读、再激发创作，做到答辩可演示、工程可持续。

## 1. 品牌气质：纸墨书卷

**母题**：一支笔、一叠稿纸、一页读本。全站统一为 **「纸墨」**——冷纸为底、墨色为骨、朱砂为点。

- 创作侧要「落笔」的手感（**第一气质**），阅读侧要「入书」的沉浸，展示侧要「书摊」的陈列感，三者由同一种纸墨统一。
- 定位是「文房器物的克制现代演绎」，**非**传统水墨国风、**非**通用后台。
- 三个场景三种书写气质：**写作用楷、阅读用宋、界面用黑**。

## 2. Design Tokens

### 2.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F7F6F2` | 全局背景，书卷底色 |
| `--paper-surface` | `#FFFFFF` | 卡片 / 稿纸面 |
| `--ink` | `#232830` | 正文主文字 |
| `--ink-secondary` | `#5A6068` | 次级文字 |
| `--ink-indigo` | `#2E4054` | 品牌主色：链接 / 标题 / 交互主色 |
| `--cinnabar` | `#B4443B` | 唯一强调色：朱批、关键动作、数据高亮 |
| `--mist` | `#97A0A8` | 辅助文字 / 分割线 |
| `--mist-line` | `#E5E2DC` | 边框 / 分隔线（纸感灰） |

纪律：强调色仅朱砂一处，全站克制；主背景取纸色，界面取纸面白，两级不混。

### 2.2 字体

| 角色 | 字体族 | 说明 |
|---|---|---|
| 书名 / 章题 | 思源宋体 SC Bold | 衬线书卷气，克制使用 |
| 阅读正文 | 思源宋体 SC Regular | 衬线阅读 |
| 创作编辑器 | 霞鹜文楷（LXGW WenKai） | 手写楷体，写作手感（现 Creator 已在用） |
| 界面 / 数据 | 思源黑体 SC / 系统无衬线 | 功能清晰 |

**落地**：中文字体按需子集化（woff2，按页面引入）；编辑器区与阅读区按各自字体族加载。

### 2.3 间距 / 圆角 / 阴影 / 动效

| Token | 值 | 说明 |
|---|---|---|
| `--space-*` | 4/8/12/16/24/32/48 | 4px 网格 |
| `--radius-sm/md/lg` | 4/8/12 | 书卷感偏小圆角，禁用大圆角「胶囊」 |
| `--shadow-card` | `0 1px 2px rgba(46,64,84,.06), 0 4px 12px rgba(46,64,84,.06)` | 纸面投影 |
| 动效 | 150–250ms `cubic-bezier(.4,0,.2,1)` | 克制；尊重 `prefers-reduced-motion` |

### 2.4 图标

统一**线性图标**（stroke≈1.6），与字体同色；避免无意义彩色图标堆叠。

## 3. 签名元素

### 3.1 创作侧：朱批旁注（Signature，核心）

AI 的续写 / 润色 / 审校结果**不以侧栏面板出现**，而以**稿纸边际的朱砂批注**浮现——像教师在作文稿边落的朱红字。

- 交互：Tiptap 中，AI 产出以浮动「朱批卡」锚定在被生成/修改的段落边际。
- 表现：朱砂红底卡、墨色文字、细朱线连接锚点；可折叠。
- 语义：`续写` / `润色` / `审校(REVISION)` 三类批注统一朱批视觉，仅标题不同。
- 这是产品最易被记住的瞬间：纸、墨、朱红合为一体，**直接体现"AI 协作文书稿"**。

### 3.2 阅读侧：墨线进度（对偶）
阅读进度用「墨线晕染」呈现——当前章节如墨滴晕开，读完留淡墨痕。与朱批「一红一墨」对偶。

### 3.3 展示侧：纸面陈列
发现 / 排行 / 书架的成果以「书封 + 书名」纸面陈列呈现（非数据表格）。

## 4. 信息架构：创作重心，门户为辅

### 4.1 主导航（创作第一）

```
[ 创作工作台 ]（主）  [ 我的书架 ]  [ 发现/排行 ]  [ 知识库 ]  用户
     ↑ 核心            展示        展示          创作
```

- 登录后默认进入**创作工作台**（若尚无作品则引导新建）。
- 阅读 / 发现 / 排行是次级入口，定位为"成果橱窗"。
- **访问控制：除登录 / 注册外，全部页面（创作、阅读、发现、排行、作品详情、书架）均需登录可见，不做未登录公开访问。**

### 4.2 页面清单（按优先级）

| 优先级 | 页面 | 现有 | 动作 | 环节 | 设计要点 |
|---|---|---|---|---|---|
| **核心** | 创作工作台 | CreatorView | 重做 | 创作 | 朱砂旁注 + 四档流水线 + 草稿/发布 |
| **核心** | 知识库 | KnowledgeBase(+List) | 重做 | 创作 | 角色/世界观/伏笔线索，巨石拆组件 |
| **核心** | 登录/注册 | Login/Register | 重做 | 参与创作 | 文房表单 + 读者转作者 |
| 辅助 | 阅读器 | ReaderView | 重做 | 阅读 | 窄栏衬线、墨线进度、翻页 |
| 辅助 | 作品详情 | （无）新增 | 阅读入口 | 封面+目录+开始阅读+参与创作 |
| 辅助 | 发现 | Discover | 重做 | 展示 | 分类书目纸面陈列 |
| 辅助 | 排行榜 | （原 /ranking 占位）新增 | 展示 | 按阅读量的轻量榜单 |
| 辅助 | 书架 | Bookshelf | 重做 | 展示 | 我的藏书 + 进度 |
| 辅助 | 落地页 | WelcomeView | 重做 | 门户 | 首屏即创作，非门户陈列 |

### 4.3 移除 / 收敛

- 删除 `Reader.vue`（与 ReaderView 重复）、`HomeView` 占位、`counter.ts` 脚手架。
- `LibraryView` 与 `Bookshelf` 二选一（保留 Bookshelf）。
- 占位路由 `/settings` `/profile` 有真实需求再做；`/ranking` 转正为排行榜页。
- 清理教学式注释（`← 加上这行` 等）。

## 5. 架构重构

### 5.1 目标目录结构

```
src/
  api/            # 重新生成的类型化客户端（pipeline / ranking / publish）
  assets/
  components/
    ui/           # 基础组件（shadcn-vue + reka-ui 纸墨主题封装）
    base/         # 业务组件：朱砂旁注 / 章节树 / 墨线进度 / 书卷卡片 / 稿纸
  composables/    # useAuth / useChapters / useAiCreation / useSse
  layouts/        # AppShell（创作台壳 / 阅读壳 / 门户壳）
  router/
  stores/
  styles/         # tokens.css + base.css
  utils/          # http.ts、sse.ts、token.ts
  views/
```

### 5.2 HTTP 层收敛

统一为单一实例 `@/utils/http.ts`：

- base 由 `VITE_API_BASE_URL || '/api'` 决定；dev 走 Vite proxy，prod 走同源 / 网关。
- 请求拦截注入 Bearer token；响应拦截处理 `40101 无权限` 与 `401`，进入**单飞刷新队列**（并发复用同一刷新 Promise，完成后**重放原请求**），修复丢请求缺陷。
- 移除 `OpenAPI.ts` 的 `http://localhost:5173/api` 硬编码。
- 流式收敛 `src/utils/sse.ts`：解析 `stage`/`content`/`revision`/`error`/`[DONE]`、超时熔断、abort、降级。

### 5.3 组件选型：shadcn-vue + reka-ui

采用 **shadcn-vue（reka-ui 无头）+ Tailwind CSS 4**。理由：视觉需完全原创，shadcn-vue 源码进项目、由 tokens 全权控制、零默认样式泄露；本项目表单/表格少、创作阅读交互皆自研，headless 交付最大控制权。

**落地清单**：

| 类别 | 内容 | 来源 |
|---|---|---|
| 基础组件 | Button / Card / Input / Textarea / Dialog / Drawer / Tabs / Select / Dropdown / Badge / Separator / Skeleton / Toast | shadcn-vue 复制 + 纸墨封装 |
| 表单校验 | reka-ui 无头 + vee-validate（或自组最小校验） | 自装 |
| 数据列表 | Card 陈列（创作/门户），无重型 data-table；分页自组 | 自组 |
| **自研签名件** | 朱砂旁注、墨线进度、稿纸编辑器、书卷卡片 | **自研** |

> 纪律：业务代码一律经 `components/ui/`、`components/base/` 引用，不得直接引入裸组件源码。

### 5.4 创作编辑器（Tiptap）

- 保留 Tiptap 封装与稿纸样式，正文用霞鹜文楷。
- 内容保存仍为 `JSONContent`；修复 `textToTiptapDoc` 段落丢失 bug（`\s+` 压单空格）。
- 朱砂旁注在 Tiptap 上用 decoration + 浮动定位实现，锚定段落边际。

## 6. 后端协作与演进

前端重做是主线；创作为主、展示为辅，后端需同步 / 前置补小量接口：

| 能力 | 现状 | 演进 |
|---|---|---|
| 作品发布二态 | 无发布状态 | `BookInfo` 增加 `草稿/发布`；发布后才进发现/排行 |
| 排行榜 | 无榜单接口 | 轻量榜单接口，**按阅读量排序**；可先由 `pageBookList` sort 兜底 |
| 参与创作 | 已有注册/登录 | 作品详情「开始创作」→ 引导注册作者 → 创作台 |
| 阅读量 | 无采集 | **本版实现**：阅读器打开章节时「阅读+1」，榜单与热度指标取自此 |

> 本版后端补充范围：轻量榜单（按阅读量）+ 发布二态字段 + 阅读+1 采集。

## 7. 迁移路线（周期充足，创作核心优先）

| 阶段 | 内容 | 预估 |
|---|---|---|
| 0 | `git init` + 首次提交 + 清理脚手架 | 0.5 天 |
| 1 | tokens.css + base 样式 + shadcn-vue 纸墨封装 | 2 天 |
| 2 | HTTP 收敛（http.ts 单飞刷新）+ sse.ts | 1–2 天 |
| 3 | **创作核心**：pipeline 对接（四档 + 朱砂旁注 + 流式 + 异步轮询 + 草稿/发布） | 3 天 |
| 4 | **创作辅助**：知识库拆分 + 创作工作台页面 | 2 天 |
| 5 | **展示辅助**：落地页 / 发现 / 排行 / 作品详情 / 阅读器 / 书架 | 3–4 天 |
| 6 | 路由清理、测试、构建与视觉验收 | 2 天 |

合计约 **14–17 天**。阶段 3–4（创作链路）优先且最重，保证核心演示物可用；阶段 5 展示辅助可并行。

## 8. 验收标准

- `vue-tsc` 0 error、`vite build` 通过。
- 全站无 Element Plus / 裸组件库遗留，视觉全部取自 tokens。
- 核心链路有测试：token 单飞刷新、SSE 事件解析、朱砂旁注段落定位、`textToTiptapDoc` 段落保留。
- 移动端响应式；键盘可访问；`prefers-reduced-motion` 生效。
- 创作闭环可演示：进入创作台 → 四档流水线 → 朱砂旁注 → 流式续写 → token 用量 → 草稿/发布 → 出现在发现/排行 → 可被阅读。

## 9. 已确认决策

- 品牌气质：纸墨书卷。
- 编辑器字体：霞鹜文楷。
- 签名元素：朱砂旁注 + 墨线进度对偶 + 纸面陈列。
- 组件选型：**shadcn-vue + reka-ui**。
- 产品重心：AI 小说创作为核心，阅读/展示为辅助。
- 参与创作：读者 → 自己创作。
- 作品可见性：草稿 / 发布 二态。
- 访问控制：**全部需登录**，无未登录公开浏览（作品库 / 排行 / 详情均需登录）。
- 排行榜：**按阅读量排序**，本版实现「阅读+1」采集。
