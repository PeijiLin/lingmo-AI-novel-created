贰 正典

World State

先记住，再动笔

长篇的难点不是写出一章，而是让几十章之后仍然自洽。World State 把人物、关系、事件、伏笔与设定写成可查询的账本，而不是塞进一段越来越长的提示词。

三时间轴事实账本
按故事时间求解当前态，历史事实软失效、不物理删除。
关系生效区间
谁与谁、在哪些章之间、是什么关系，都带区间。
事件因果链
caused_by 连成链，时序倒错可以被确定性判定。
伏笔排期
埋设与回收有章距，逾期会告警而不是静默遗忘。
闭世界知情
knows 集合明确角色知道什么，不知道的事不能写成知道。
定长摘要树
章 / 段 / 书三级摘要，上下文不随章节数线性膨胀。
RAG 检索
按 bookId 过滤，召回相关历史片段作为写作与审查证据。
断言与冲突
抽取结果分级入账，冲突进入人审队列而不是悄悄覆盖。

叁 自主

Bounded Autonomy

有界自主，不是放任

循环机制归代码，步骤决策归模型。每一步只允许三种出口：去取证、去问人、或者收口。围栏先于自主性上线，没有围栏就不开 L2。

01THINK → 02ACT → 03OBSERVE
步数上限 token 预算 墙钟 工具白名单 防复读熔断 无递归派生

失败或被拒的工具不推进状态；连续失败自动回退 L1 单次调用。ask_human 会挂起整个 run，可以跨天等一个答案。

STEP PROTOCOL每一步，三选一
// 取证
{"type":"tool_call","tool":"canon.query",
 "args":{"subject":"林岸.左臂"},"reason":"核对旧伤位置"}

// 问人（挂起，不占超时）
{"type":"ask_human",
 "question":"密道入口是否已被主角发现？","blocking":true}

// 收口（必须过代码校验）
{"type":"finish","deliverable":{...},
 "claims":[{"text":"...","evidence":["ev://ch12/s3"]}]}
肆 防线

Safety

三道门，一道都不能少

安全不是可调参数。三道门覆盖输入、生成过程与定稿，且不进入降级域 —— 即使预算触顶、Critic 被跳过，它们仍然在工作。

PRE

输入前置

纯代码、零成本、零延迟。拒绝物理上不可满足的约束与高置信提示注入；可疑表达标记放行，宁记不杀。

STREAM

流式中置

生成过程中持续扫描，命中即断流；截断后重新生成，不把风险内容交给前端。

POST

定稿后置

词表 gate 命中后先做修复式改写；仍然命中则转人审队列，并留下双指标审计记录。

InputGuard → StreamGuard → FinalDraftGate，全过程写入安全审计账本；安全层不设开关。

伍 工程

Engineering

让长跑可算、可停、可复现

写一部长篇是长跑。成本要能算，失败要能停，实验要能重放 —— 这些不是附属功能，而是流水线的一部分。

BUDGET

预算三级链

书级硬上限、章级 token / 时延 / 成本、轮级 40% 配额；超限产生降级决策而不是无限重试。

LADDER

L1–L4 降级

关 best-of → 收紧重写 → 跳过 Critic / Polisher → 停笔转人工。安全与硬校验始终保留。

CHECKPOINT

节点断点续跑

幂等键加输入指纹判定复用，中断后从首个未完成节点继续，已完成节点不重复计费。

LEDGER

成本账本

按 stage / Agent / model 计价，汇总查询与 CSV 导出，能对得上一章花了多少。

REPLAY

录制与回放

模型调用落盘 JSONL 并归档 MinIO；失败样本可以原样重放，实验不必重烧一遍。

ABLATION

五个消融开关

默认全关等于现状行为，支持请求级覆盖做同部署双跑，一次只开一个变量。

陆 开始

Get Started

在自己的机器上跑起来

需要 JDK 17、PostgreSQL 15+（pgvector）、Redis、Kafka 与 MinIO。模型走 OpenAI 兼容协议，密钥只放在本地配置里。

  1. 一

    克隆仓库

    前后端分仓，后端为当前仓库。

  2. 二

    初始化数据库

    业务库与向量库分别建库，再执行累积 DDL。

  3. 三

    写本地配置

    application-dev.yml 不入库，按 README 覆盖数据库与模型配置。

  4. 四

    启动

    默认端口 8088，接口前缀 /api；Knife4j 文档在 /api/doc.html。

TERMINAL3 commands
$ git clone https://github.com/PeijiLin/lingmo-AI-novel-created.git

# 业务库：角色卡 + 多智能体累积 DDL
$ psql -U postgres -d novel_system -f sql/multi_agent.sql

# 启动（端口 8088，context-path /api）
$ mvn spring-boot:run
